## ⚡ 10 秒看懂 AI Agent

```
傳統生成式 AI（如網頁版 ChatGPT）：
大腦 🧠  ──(只能打字)──> 人類 🧑‍💻 ──(手動搬運、手動寫程式)──> 完成任務

現代本機 AI Agent（如 Claude Code / AntiGravity）：
大腦 🧠 ＋ 工具手腳 🦾（終端機、讀檔、寫檔、上網、跑程式） ──> 直接在你的電腦產出成果！
```

## 📚 必知核心名詞字典

| 名詞 | 英文術語 | 一句話白話解釋 |
|:---|:---|:---|
| **大型語言模型** | LLM | Agent 的「思考大腦」，負責理解語意、推理邏輯、產生決策。 |
| **智慧代理人** | Agent | 大腦配上「環境感知與操作工具（手腳）」，能自主完成連續多步驟目標。 |
| **工具呼叫** | Tool Use / Function Calling | 大腦決定「何時使用終端機、何時讀寫檔案、何時上網」，賦予 AI 改變真實世界的能力。 |
| **上下文視窗** | Context Window | AI 在一次對話中能「同時看見」的最大文字容量；塞滿雜訊會導致 AI 越聊越笨。 |
| **記號 / 代幣** | Token | AI 計算文字與計費的基本單位（約 1 個中文字 = 1~2 Tokens）。 |
| **專案藍圖** | `agents.md` / `CLAUDE.md` | 放在專案資料夾根目錄的「專案使用手冊」，任何 Agent 接手都先讀它。 |
| **交接檔** | `handoff.md` | 記錄「目前做到哪、下一步做什麼」的接力棒檔案，換對話或換電腦必備。 |
| **版本控制** | Git (`git init`) | 程式碼與檔案的時光機，讓你不怕 Agent 誤改或刪壞檔案。 |

## 🧠 三師爸 Agent 操作四大心法口訣

1. **目標明確，給足脈絡**：
   - ❌ *「幫我把考卷改一下」*（太模糊，AI 會猜測你的意思）。
   - ✅ *「請讀取 `exam.docx`，將所有單選題的選項打亂，並在文末產出一份新的解答對照表存為 `exam_new.docx`」*。
2. **長聊必笨，定期交接**：
   - 當一個階段任務完成（或對話超過 20 輪），立刻指示 Agent：*「請把目前進度寫入 `handoff.md`」*。
   - 接著開新對話：*「請讀取 `agents.md` 與 `handoff.md` 接續下一步」*。
3. **分級派工，節省成本**：
   - 規劃大架構用旗艦 S 級模型；寫代碼實作用主力 A 級模型；抓資料查檔案用輕量 B 級模型。
4. **遇錯莫慌，讓它自修**：
   - 終端機報錯時，不要自己慌忙上 Google 查，直接把報錯複製給 Agent：*「出現了上述錯誤，請分析原因並修正後重新執行」*。

## 🚫 新手常見 5 大踩坑與避坑對策

| 踩坑情境 | 為什麼會發生？ | 正確避坑解法 |
|:---|:---|:---|
| **AI 開始胡言亂語、忘記前面的規定** | Context Window 被過多雜訊撐爆（Attention Drift）。 | 不要死守原對話！總結進度至 `handoff.md`，清空對話重新出發。 |
| **重要的檔案被 Agent 一口氣覆蓋掉了** | 未開啟 Git 版本控制，且給予了過大權限。 | 一開始務必 `git init`，並在修改前請 Agent 先保留原檔備份。 |
| **執行 Python 程式一直噴缺少套件錯誤** | 本機 Python 環境尚未安裝對應函式庫。 | 直接指示 Agent：*「請檢查缺少的套件並自動幫我安裝」*。 |
| **API 額度快速見底、費用飆高** | 在長對話中反覆灌入超大文件或圖片。 | 善用本地檔案讀取工具，只提取關鍵章節，避免全量重讀。 |
| **換另一台電腦後，AI 完全不知道專案背景** | 沒有建立跨裝置的標準藍圖與雲端同步。 | 將專案放在 Google 雲端硬碟，並隨時維護 `agents.md` 與 `handoff.md`。 |
